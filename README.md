# Nova Marko

Marketing site for Nova Marko — build, brand, scale — built with Next.js (App Router) and Tailwind CSS.

## Run locally

**Prerequisites:** Node.js 18.18+

1. Install dependencies:
   `npm install`
2. Run the dev server:
   `npm run dev`
3. Open [http://localhost:3000](http://localhost:3000)

## Build

`npm run build` produces a static-optimized production build; `npm start` serves it.

## Deploy

This is a standard Next.js App Router project — push it to a Git repo and import it on [Vercel](https://vercel.com/new) with no extra configuration. Vercel auto-detects the framework, install command, and build command from `package.json`.
